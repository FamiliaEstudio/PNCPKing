# PNCP King 1.2.21

- **Atualizar pelo GitHub** instala e reinicia o programa antes de baixar ou importar o pacote de preços. A etapa dos preços continua automaticamente após o reinício; uma falha nessa etapa mantém o programa atualizado e permite retomar.
- Novo botão **Transferir item…** na janela do item: escolha outro projeto local para mover o item com todos os preços, cestas, evidências, descritivo, quantidades, CATMAT e pesquisas individuais, sem duplicação.
- O item entra como item solto no destino e deixa a automação do projeto de origem. Pause a automação antes de transferir. Projetos já organizados precisam de nova organização; ao mudar entre cotação comum e de medicamentos, a cesta deve ser confirmada novamente segundo a precisão do destino.
