- A recepção de atualizações PNCP agora aplica cada bloco consultando pelos índices somente os itens e resultados necessários, evitando percorrer todo o banco a cada dia e reduzindo o trabalho em PCs com HD lento.
- A janela **Atualizar pelo GitHub** permite escolher somente o programa, somente os preços ou ambos. A escolha é preservada após o reinício; pacotes que exigem uma versão nova só ficam disponíveis junto com a atualização do programa.
- O banco que exporta um pacote passa a reconhecê-lo como já presente, dispensando sua reimportação. Essa identificação vale para exportações feitas a partir desta versão.
- A importação mostra separadamente a leitura e a aplicação de cada bloco. Cancelamento e retomada continuam preservando os blocos já concluídos.
