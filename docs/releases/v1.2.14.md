# PNCP King 1.2.14

- Agora é possível arrastar as colunas dentro de “Escolher colunas” para mudar sua ordem com mais rapidez. A linha de inserção mostra onde a coluna ficará, e a lista rola ao arrastar perto das bordas.
- A escolha por posição numerada continua disponível. Arrastar altera somente o rascunho: “Aplicar” salva a nova ordem e “Cancelar” a descarta, sem mudar a visibilidade das colunas.
