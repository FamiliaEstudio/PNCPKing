# PNCP King 1.2.15

- Na pesquisa principal, use `+` para combinar pesquisas independentes, como `café torrado + açúcar cristal`. Espaços continuam exigindo os termos juntos, e cada trecho mantém suas próprias exclusões e unidades.
- O botão “Carregar mais resultados” alterna páginas de até 50 preços entre os trechos, sem duplicatas. A leitura continua usando o buscador local existente, uma pesquisa por vez, para controlar o trabalho no disco.
- Pesquisas com `+` usam somente o banco local. Cancelamento, retomada e atualização dos filtros preservam a continuidade; os critérios salvos em Cotações mantêm seu significado anterior.
