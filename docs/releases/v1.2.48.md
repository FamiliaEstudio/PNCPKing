# PNCP King 1.2.48

- Ao importar a base de preços, o programa confere o esquema do banco local antes de descompactar o pacote. Se encontrar uma estrutura incompatível, interrompe a importação nessa etapa. A conferência sob bloqueio continua protegendo a troca final.
- O log identifica o banco local ou o pacote, o arquivo, a tabela, o índice ou o gatilho recusado e sua definição SQL armazenada. A versão 1.2.48 coleta o diagnóstico com os critérios de compatibilidade da 1.2.47.
- Na mensagem de erro, o usuário pode autorizar o envio de um TXT com o registro daquela ocorrência para felipearcencio@gmail.com. O programa de e-mail configurado no Windows tenta encaminhá-lo. Se o envio automático estiver indisponível, o PNCP King prepara um rascunho com o anexo e informa onde localizar o TXT para uso no webmail.
- A opção **Diagnóstico → Enviar último erro desta sessão por e-mail** permite retomar o envio. Cada tentativa exige autorização.
